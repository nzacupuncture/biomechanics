# Attribution

This project contains geometry derived from:

- **Z-Anatomy, the libre 3D atlas of anatomy** (CC BY-SA 4.0).
  Gauthier Kervyn (design, 3D, anatomy), Marcin Zielinski (Blender add-on) and contributors.
  https://github.com/Z-Anatomy/Models-of-human-anatomy
- **BodyParts3D**, The Database Center for Life Science (CC BY-SA 2.1 Japan).
  https://dbarchive.biosciencedbc.jp/en/bodyparts3d/download.html

Changes made: bone meshes extracted and simplified; the arm re-posed (humerus vertical, elbow
flexed); muscle attachment points, joint centre and axes derived from the meshes; attachment
footprints coloured onto bones. Muscle lines of action and all code are original to this project.
